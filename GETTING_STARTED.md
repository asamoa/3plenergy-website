## 🎯 3 Simple Steps to Go Live

### Step 1: Preview the Website (Right Now!)
```bash
cd website
python3 -m http.server 8000
```
Then open: http://localhost:8000

**Or** just double-click `index.html` in the website folder!

---

### Step 2: Set Up Contact Form (5 minutes)
So visitors can send you enquiries via email:

1. Go to https://formspree.io and sign up (FREE)
2. Create a new form: "3PL Energy Contact Form"
3. Copy your form ID
4. Open `index.html` and find line 232
5. Replace `YOUR_FORM_ID` with your actual ID
6. Done!

**See `FORMSPREE_SETUP.md` for detailed instructions.**

---

### Step 3: Deploy Online (FREE hosting)
Choose one (all are free):

**Option A: Netlify (Easiest)** ⭐
1. Go to https://netlify.com
2. Drag the `website` folder onto their page
3. Your site is live instantly!

**Option B: GitHub Pages**
1. Upload files to GitHub
2. Enable Pages in settings
3. Site goes live

## 🎨 Want to Customize?

### Add Your Logo
1. Save logo as `logo.png` in the website folder
2. Open `index.html`
3. Find line 15 (the navigation)
4. Replace the `<h2>3PL Energy LTD</h2>` with:
```html
<img src="logo.png" alt="3PL Energy LTD" height="40">
```

### Change Colors
1. Open `styles.css`
2. Find lines 11-13 (the color variables)
3. Change the hex codes to your preferred colors

### Update Content
1. Open `index.html`
2. Find the text you want to change
3. Edit and save!
